To generate the PDF for submission:

1. Open the file "Project_Definition.html" in your web browser (Chrome, Edge, Firefox).
2. Right-click on the page and select "Print" (or press Ctrl+P).
3. In the "Destination" or "Printer" dropdown, select "Save as PDF".
4. Click "Save" and choose this location to save your "Project_Definition.pdf".

This method ensures the best formatting as per the project requirements.
