# Code Agent V4

This is **Code Agent V4**, a fully functional AI Code Assistant powered by Local Ollama models (such as `qwen2.5-coder` or `llama3`) running within WSL, with a Next.js React frontend and a FastAPI Python backend.

## 🚀 Features

- **Conversational UI**: A sleek, modern chat interface tailored for coding sessions.
- **Autonomous Tool Execution**: The agent automatically runs tools like web searches, file creation, editing, and terminal commands to fulfill your requests.
- **Dynamic Activity Log**: Real-time status updates and execution progress (Thinking, Running Tools, Verification, Success/Error logs).
- **Interactive Code Previews**: Directly view the files the agent modifies within the application.
- **Workspaces & Sessions**: Organize your projects into separate folders and maintain different chat histories.

## 📁 Repository Structure

- `frontend/`: Next.js 14 React application tailored with Tailwind CSS and Lucide Icons.
- `backend/`: FastAPI application that integrates with LiteLLM for routing LLM requests, containing the core code for executing model reasoning loops, parsing tools, and performing completion verifications.
- `code_agent/`: Core Python classes handling tool implementations (Code Editing, Web Search, Terminal Commands).
- `Created Programs/`: A folder to store programs generated by the agent. Includes a fully functional `Calculator` built entirely autonomously by the agent!

## 🛠️ Required Setup

### 1. Environment Variables
To run the agent locally, you'll need API keys for specific external tools. Copy the `.env.copy` file to `.env` and fill in your keys:
```bash
cp .env.copy .env
```

Specifically, you'll need the `TAVILY_API_KEY` if you want the agent to be able to perform web searches, and `USE_LOCAL_OLLAMA=True` to utilize your local Ollama instance.

### 2. Running the Backend
The backend utilizes Python 3.12+ and FastAPI. First install the required dependencies (assuming a virtual environment is active):
```bash
pip install -r requirements.txt
python backend/server.py
```
This will start the backend server on `http://localhost:8000`.

### 3. Running the Frontend
The frontend requires Node.js.
```bash
cd frontend
npm install
npm run dev
```
Access the UI via `http://localhost:3000`.

